Es proyecto ha consistido en hacer una calculadora de descuentos con condiciones. Las condiciones en este caso son:
    Descuento del 15% si gastas 300€ o más.
    Descuento del 10% si gastas entre 100€ y 299.99€.
    Si gastas menos de 100, no tienes descuento.
    En caso de ser negativo, este dará error: "importe no válido".

--------------------------------------

# ¿Cómo funciona?
Cuando activas el programa, este te pedirá que introduzcas un monto en la terminal. El código detectará ese monto, lo analizará y aplicará las reglas mencionadas antes.

# ¿Qué resultados obtienes?
Cuando termina de analizar el monto introducido, este dará 4 resultados, los cuales son:

    1: Importe original
    2: Descuento aplicado
    3: Ahorro obtenido
    4: Total a pagar
# Requisitos
Tener Python en la version 3.14

# ¿Cómo se activa?
1. Abre una terminal o consola.
2. Ve a la carpeta del proyecto.
3. Ejecuta este comando:

```bash
python calcular_descuento_basico.py
```

4. Introduce el importe cuando el programa te lo pida.
